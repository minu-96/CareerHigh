# 커리어 하이 (Career High)

무작위로 정해진 출발점에서 시작해 정년까지 한 사람의 직업 인생을 사는 웹 게임입니다.
1턴은 1년이고, 17~20세에 시작해 65세에 끝납니다. 한 판은 10~15분쯤 걸립니다.

현재 버전: **9판** (프로토타입)

**바로 하기: https://minu-96.github.io/CareerHigh/**

지난 판도 주소 뒤에 판 번호를 붙이면 해 볼 수 있습니다. 예: https://minu-96.github.io/CareerHigh/v3/ (`v1` ~ `v9`)

## 어떤 게임인가

시작할 때 나이, 출신 집안, 학력, 하고 싶은 직군이 무작위로 정해집니다.
매년 네 번의 분기를 업무, 공부, 인맥, 투자, 가족, 휴식 같은 행동에 나눠 쓰고,
그해에 찾아온 사건 카드에서 선택을 합니다. 그렇게 쌓인 한 해 한 해가 이력서와 명함으로 남습니다.

"최고가 되는 방법"은 하나가 아닙니다. 길은 여섯 갈래이고 각각 꼭대기가 따로 있습니다.

| 길 | 무엇을 쌓나 |
|---|---|
| 조직 | 승진해서 회사의 꼭대기까지 오른다 |
| 장인 | 능력을 키우고 그 일의 대표 업적을 남긴다 |
| 창업 | 내 회사를 차려 키운다 |
| 명성 | 업계 밖에서도 이름이 알려진다 |
| 자산 | 모으고 굴려서 불린다 |
| 삶 | 가족과 일상을 지킨다 |

한 길만 파도 되고, 중간에 갈아타도 됩니다. 대신 번아웃, 파산, 구조조정처럼 인생을 꺾는 일도 일어납니다.

## 직군

지금은 10개 직군이 들어 있습니다. 직군마다 직급 이름, 사건 카드, 회사, 명함이 다릅니다.

소프트웨어 개발, 게임 개발, 요리·외식, 기업 경영·사무, 기계·제조, 은행·금융, 의료, 교육·학원, 영업·유통, 건설 현장

장인의 길에서 쌓는 것의 이름도 직군마다 다릅니다. 개발자는 대표작, 요리사는 대표 메뉴, 영업은 대표 실적, 건설은 대표 시공을 남깁니다.

## 이 게임만의 것

- **명함**: 직군, 직무, 직급, 회사에 따라 디자인이 다른 명함 433종. 승진하거나 회사를 옮길 때마다 새 명함을 받고, 도감에 모입니다.
- **이력서와 업무 수첩**: 이력서에는 내세울 것만 적히고, 이력서에 못 쓴 일은 업무 수첩에 따로 남습니다.
- **버킷리스트**: 인생마다 목표 3개가 주어집니다.
- **특성**: 6년마다 하나씩 고르는 특성 16종.
- **인생 요약**: 끝낸 인생마다 어떻게 살았는지 글과 연표, 명함으로 다시 볼 수 있습니다.
- **커리어 타운**: 지금까지 살아 본 사람들이 한 동네에 모여 걸어 다니고, 마주치면 서로의 인생을 두고 말을 겁니다.

## 실행

설치나 빌드가 필요 없습니다. 저장소를 받아 `index.html`을 브라우저로 열면 됩니다.

- 글꼴은 Google Fonts에서 불러오므로 인터넷이 연결돼 있어야 의도한 모습으로 보입니다.
- 진행 상황과 지난 인생 기록은 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.
- `index.html#seed`로 열면(파일로 직접 열었고 기록이 비어 있을 때만) 자동으로 일곱 명의 인생을 만들어 커리어 타운을 바로 확인할 수 있습니다. 개발용 기능입니다.

## 배포

GitHub Pages로 배포합니다. `gh-pages` 브랜치의 내용이 그대로 사이트가 되고, 최신 판은 맨 위에, 지난 판은 `v1/` ~ `v8/` 폴더에 들어 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 진입점. 아래 스크립트를 순서대로 불러온다 |
| `data.js` | 규칙, 능력치, 출신, 특성, 기본 직군 3개, 사건 카드 |
| `jobs2.js` | 추가 직군 7개와 그 사건 카드, 시대 흐름 |
| `engine.js` | 게임 규칙. 화면과 분리돼 있어 Node에서도 돌아간다 |
| `cards.js` | 명함 디자인과 회사 브랜드 |
| `ui.js` | 화면, 입력, 효과음, 커리어 타운 |
| `style.css` | 스타일 |
| `tools/sim.js` | 자동 플레이 시뮬레이터 |

새 직군을 넣을 때는 `jobs2.js`에 직군 정의와 사건 카드를, `cards.js`에 회사 브랜드와 직함을 추가합니다.

## 밸런스 시뮬레이터

엔진만 불러 여러 판을 자동으로 돌리고, 길마다 정점에 도달한 비율과 결말 분포를 보여 줍니다.

```
node tools/sim.js . 400
```

7판 기준으로 한 길만 판 봇의 정점 도달률은 조직 9%, 장인 8%, 창업 11%, 명성 7%, 자산 9%, 삶 18%쯤이었고, 아무렇게나 고르는 봇은 1%였습니다.

## 버전 기록

판별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다. 1판부터 9판까지 판마다 커밋 하나, 브랜치 하나(`v1` ~ `v9`)가 있고, `main`은 항상 최신 판입니다.

```
git checkout v1     # 1판 보기 (v2 ~ v9도 같은 방식)
git checkout main   # 최신으로 돌아오기
```

1~2판은 `index.html` 한 파일이고, 3판부터 파일이 나뉩니다. 어느 판이든 `index.html`을 열면 실행됩니다.

## 알려진 한계

- 직군별 빈도가 고르지 않습니다. 건설과 영업은 자주, 은행과 의료는 드물게 나옵니다. 특히 의사가 되기가 어렵습니다.
- 효과음과 다크 모드는 충분히 확인하지 못했습니다.
- 좁은 화면의 커리어 타운에서 캐릭터 이름표가 겹칠 때가 있습니다.
- 7판 이전에 남긴 지난 인생 기록은 이름과 결말만 있어서 요약이 나오지 않습니다.
