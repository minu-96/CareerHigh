# 커리어 하이 11판 디자인 설계

작성: 강민우 · 2026-11-19

11판은 규칙을 거의 건드리지 않고 보이는 것을 고치는 판이다. 가장 큰 일은 명함이고, 화면 점검에서 나온 나머지 문제를 함께 고친다.

## 점검 결과

10판을 휴대폰(400px)과 PC(1280px)에서 한 판씩 끝까지 하며 모든 화면을 찍었다.

| 화면 | 문제 |
| --- | --- |
| 명함 | 도감은 433종이지만 틀은 10개쯤이다. 같은 회사의 1·3·5단계는 직함 글자와 테두리만 다르고, 6단계는 모든 회사가 같은 검정·금색 명함이다. 의료와 건설은 틀까지 같다. 창업 4~5단계 명함은 흰 종이에 글자뿐이다. |
| 사건 카드 | 글과 선택지만 있다. 회사 일, 연애, 시대 사건이 모두 같은 모습이다. 10판의 시대 카드와 지난 인생 카드도 '인생'이나 '회사'로 분류된다. |
| 커리어 타운 (휴대폰) | 10명이 차면 한 집이 40px 폭이라 사람이 집보다 크고 서로 겹친다. |
| 인생 요약 연표 | 10판에서 넣은 연도 때문에 "19세"가 "19 / 세"로 줄이 바뀐다. |
| 계획 책상 (휴대폰) | 손에 든 행동 카드 8장의 설명이 11px로 빽빽하다. |
| 수집첩 | 정점 도장판이 빈 동그라미 60개뿐이다. 무엇을 모으는 판인지 보이지 않는다. |
| 타이틀 | 하늘이 비어 있고, 지난 인생의 흔적이 타운 버튼 글자 하나뿐이다. |

## 1. 명함

명함 한 장은 네 가지가 겹쳐 정해진다. 회사(지금처럼), 직급 마감, 시대 양식, 직군 신분증이다. 드문 변형이 그 위에 낮은 확률로 붙는다.

### 1-1. 직급마다 종이와 마감이 오른다

같은 회사 명함 6장을 늘어놓으면 승진이 눈에 보여야 한다.

| 단계 | 마감 |
| --- | --- |
| 1 | 얇은 단면 종이. 로고는 회색 한 가지 색. 영문 표기 없음. 수습 도장 |
| 2 | 기본 명함 |
| 3 | 로고가 회사 색으로 찍힌다. 영문 직함이 붙는다 |
| 4 | 회사 색 띠가 두꺼워지고 팀 이름이 앞에 나온다 |
| 5 | 두꺼운 종이(그림자가 깊다). 로고에 엠보싱, 가장자리에 금색 선 |
| 6 | 회사 색 바탕에 금박 글씨. 회사마다 다른 정점 명함 |

창업 명함도 같은 사다리를 탄다. 1단계는 직접 인쇄한 명함, 3단계는 크라프트지, 5단계부터 회사 색 바탕이다.

### 1-2. 시대마다 인쇄 양식이 다르다

명함을 받은 해의 연도로 양식을 고른다. 같은 회사, 같은 직급이라도 1988년 명함과 2018년 명함은 다르다.

| 시대 | 양식 |
| --- | --- |
| 1975~1989 활판 | 미색 종이, 명조체, 잉크가 살짝 번진다. 이름 옆에 한자 성. 회사 대표 전화와 교환 번호. 이메일 없음 |
| 1990~1999 PC 통신 | 직통 전화와 삐삐 번호(012·015), PC 통신 ID. 로고 아래 그러데이션 띠 |
| 2000~2009 닷컴 | 011·016·017·019 휴대폰, 이메일, 홈페이지(www.○○.co.kr). 로고에 광택 |
| 2010~2019 모바일 | 010 휴대폰, 이메일, 모서리에 QR 코드. 납작한 디자인 |
| 2020년 이후 미니멀 | 큰 여백, 연락처는 이메일과 SNS 계정 하나 |

### 1-3. 직군 신분증

일부 직군의 낮은 단계는 명함 대신 그 일터의 신분증을 받는다.

| 직군 | 단계 | 신분증 |
| --- | --- | --- |
| 게임 개발 | 1~2 | 목걸이 사원증 (세로형, 사진, 출입 바코드) |
| 의료 | 1~3 | 가운에 다는 이름표 (진료과, 면허 번호) |
| 건설 현장 | 1~2 | 현장 출입증 (안전모 스티커, 혈액형, 비상 연락처) |
| 요리·외식 | 1~2 | 앞치마 이름표 (주방 파트) |
| 교육·학원 | 1~3 | 강사 프로필 카드 (담당 과목, 한 줄 소개) |
| 은행·금융 | 1~2 | 창구 명패 |

### 1-4. 드문 변형

명함을 받을 때 낮은 확률로 붙는다. 같은 명함이라도 변형은 따로 모인다.

| 변형 | 조건과 확률 | 모습 |
| --- | --- | --- |
| 펜으로 고친 직함 | 승진해서 받은 명함, 8% | 옛 직함에 줄을 긋고 손글씨로 새 직함 |
| 오타 명함 | 4% | 이름 한 글자가 틀려 정정 스티커가 붙어 있다 |
| 커피 자국 | 번아웃 60 이상일 때 받은 명함, 10% | 모서리에 컵 자국 |
| 별명 명함 | 별명이 붙은 뒤 받은 명함, 15% | 이름 아래 손글씨로 별명 |
| 해외 지사 | 지방·해외 근무를 고른 해, 100% | 영문이 위로 올라온 명함 |

### 1-5. 도감

- 지금의 433칸(회사 × 직급)은 그대로 둔다. 칸 하나에 시대 양식 5개가 들어간다.
- 칸의 점은 모은 시대 수만큼 채워진다(점 하나를 5등분한 고리).
- 도감 위에 세 숫자를 둔다: 명함 433, 시대 양식 433×5, 드문 변형 5.
- 지난 인생의 회사 칸(10판)은 그대로 따로 둔다.

## 2. 사건 카드

- 분류를 둘 늘린다: '시대'(연도 조건이 있는 카드), '지난 인생'(지난 인생의 회사 카드).
- 분류마다 작은 그림을 카드 오른쪽 위에 둔다.

| 분류 | 그림 |
| --- | --- |
| 갈림길 | 갈림길 표지판 |
| 회사 | 서류 더미와 모니터 |
| 사업 | 가게 차양 |
| 프리랜서 | 노트북과 커피 |
| 학창 시절 | 책가방 |
| 명성 | 마이크 |
| 인생 | 집과 하트 |
| 직군 카드 | 그 직군의 도구 (키보드, 프라이팬, 청진기, 안전모 등 10종) |
| 시대 | 접힌 신문, 그해 연도가 찍힌다 |
| 지난 인생 | 빛바랜 사진 |

- 시대 카드에는 위에 "1997년" 같은 연도 띠를 단다.

## 3. 커리어 타운

- 휴대폰에서는 길을 옆으로 넓힌다. 한 사람에 최소 88px을 주고, 넘치면 손가락으로 옆으로 밀어 본다.
- 처음 열면 가장 최근 인생이 화면 가운데 오도록 스크롤한다.
- 길 끝에 "← 밀어서 이웃 보기" 안내를 한 번 보여 준다.

## 4. 작은 화면 정리

- **인생 요약 연표:** 연도와 나이를 한 줄로 쓴다("2002 · 19세"). 칸 폭을 넓혀 줄이 바뀌지 않게 한다.
- **휴대폰 계획 책상:** 손에 든 카드는 이름을 크게, 설명은 핵심 효과 한 줄만 보인다. 전체 설명은 칸에 붙인 뒤 아래 미리보기 줄에서 본다.
- **수집첩 정점 도장판:** 빈 칸에 그 길 색의 옅은 점선 도장 테두리를 그린다. 찍힌 칸은 기울어진 붉은 도장과 달성 나이.
- **타이틀:** 지난 인생이 있으면 제목 아래에 최근 명함 세 장을 부채꼴로 펼친다. 누르면 타운으로 간다.

## 확인할 것

- 명함 갤러리: 같은 회사 1~6단계, 시대 다섯 개, 직군 신분증 여섯 개, 드문 변형 다섯 개가 한눈에 다르게 보일 것.
- 명함 글자가 휴대폰의 작은 명함(78px)에서도 넘치지 않을 것.
- 지난 기록(10판 이전)의 명함은 연도가 없으므로 2010년대 양식으로 그린다.
- 휴대폰(400px)과 PC(1280px) 스크린샷으로 모든 화면 확인. 시뮬레이터 에러 0.
