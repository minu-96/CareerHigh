# 커리어 하이 기획서

작성: 강민우 · 2026-11-19

## 개요

커리어 하이는 무작위로 정해진 출발점에서 시작해 65세 정년까지 한 사람의 직업 인생을 사는 웹 게임이다. 1턴은 1년이고, 매년 행동력을 나눠 쓰고 그해의 사건에서 고른다. 끝나면 최종 이력서와 마지막 명함이 남고, 그 사람은 커리어 타운으로 이사한다.

- **원작에서 가져온 것:** 고를 수 없는 출발점, 텍스트 사건으로 흘러가는 인생, 공유할 수 있는 결과, 서버 없는 정적 웹
- **원작과 다른 것:** 무대가 일과 성장이다. 최고가 되는 길은 조직, 장인, 창업, 명성, 자산, 삶 여섯 갈래이고 직군마다 정점의 이름이 다르다. 끝은 죽음이 아니라 정년, 쓰러짐, 파산, 또는 스스로 내려오는 은퇴다.
- **지금 상태:** 8판 프로토타입. 직군 10개, 사건 카드 134장, 명함 433종. [배포 주소](https://minu-96.github.io/CareerHigh/), [저장소](https://github.com/minu-96/CareerHigh)

## 차별화 방향

원작의 후속작처럼 보이지 않도록 소재보다 플레이어의 행동, 화면, 판 사이의 연결을 바꾼다.

| 요소 | 80억분의 1 | 커리어 하이 |
| --- | --- | --- |
| 플레이어 행동 | 대부분 지켜보고 가끔 고름 | 매년 행동력 4칸을 나눠 쓰고, 사건에서 고른다 |
| 화면 | 텍스트 로그가 쌓임 | 나이에 따라 하늘이 바뀌는 도시, 책상 위 손패, 이력서와 명함. 전체 기록은 업무 수첩에 |
| 출발점 공개 | 출생 확률(%)로 운을 강조 | 통지서를 한 장씩 넘기는 연출, "이의 신청" 다시 뽑기 |
| 분위기 | 진지하고 숙연함 | 성장하는 쾌감과 직장인 공감 유머 |
| 사람 | 가족 중심, 대부분 스쳐 감 | 입사 동기와 상사가 반복 등장한다 |
| 끝 | 죽음과 장례 | 정년 퇴임, 쓰러짐, 파산, 스스로 내려옴. 최종 이력서와 마지막 명함 |
| 판 사이 | 캠릭터들이 모인 마을 | 지난 인생들이 집이나 회사와 함께 사는 커리어 타운. 이전 생의 회사가 다음 생에 다시 나온다 |

### 두 가지 기록

이력서는 남에게 보여 주는 공식 기록이라 좋은 것만 남는다. 그래서 모든 사건은 업무 수첩에 따로 남긴다.

| 기록 | 담기는 것 | 역할 |
| --- | --- | --- |
| 이력서·명함 | 학력, 입사·승진·이직, 창업, 수상 등 공식 이력만 | 화면의 중심. 승진·이직할 때마다 줄이 늘고 명함이 바뀜다 |
| 업무 수첩 (전체 기록) | 탈락, 실패, 퇴사, 번아웃까지 모든 사건 | 언제든 열어 보는 기록. 이력서에 안 나오는 사연이 담긴다 |

이력서의 공백기를 누르면 수첩의 그해 기록으로 이어진다. 엔딩에서는 이력서에 못 쓴 이야기 3가지가 공개된다.

## 시작 설정

출발점은 통지서 여덟 장으로 한 장씩 공개된다. 앞에서 뽑힌 값이 뒤의 후보와 확률을 정하는 조건부·가중 랜덤이다. 마음에 안 들면 "이의 신청"으로 다시 뽑는다(처음 1장, 수집으로 늘어남).

| 항목 | 뽑는 법 | 내용 |
| --- | --- | --- |
| 나이 | 17\~20세 균등 | 17세는 고등학교 입학, 20세는 대학 입학 시기 |
| 시작 연도 (새로) | 1975\~2025년 균등 | 그해에 위 나이가 된다. 시대 사건과 열려 있는 직군이 정해진다 (시대와 연도) |
| 출신 | 8종 가중 랜덤 | 시작 현금·능력·인맥 보정 (출신과 특성) |
| 학력 | 출신 연동 가중 랜덤 | 17\~19세는 고교 유형, 20세는 4년제·전문대·취업 |
| 타고난 것 / 모자란 것 | 장점 1, 단점 1 | 규칙을 바꾸는 특성 |
| 하고 싶은 일 (지망 직군) | 학력 연동 가중 랜덤, 10%는 학력과 무관 | 직위가 아니라 방향. 시작 연도에 아직 없는 직군은 나오지 않는다 |
| 버킷리스트 | 15개 중 3개 | 인생의 부목표. 달성하면 수집첩에 남는다 |

- 출신은 확률을 기울일 뿐 결정하지 않는다. 불리한 출신도 역전할 수 있다.
- 지망은 시작점일 뿐이다. 졸업 때 지원서를 쓰고, 합격·탈락이 있고, 중간에 다른 분야로 틀 수 있다.
- 의료처럼 4년제가 필요한 직군은 조건이 안 되면 지망을 접고 다른 직군으로 바뀐다.

## 시대와 연도 (새로)

매 판은 시작 연도를 갖고, 나이가 한 살 오를 때마다 연도도 한 해 간다. 그해가 어느 시대인지가 직군의 형편과 사건을 정한다. 금액은 모든 시대에서 지금 돈 기준으로 통일하고 물가는 계산하지 않는다.

| 연도 | 고정 사건 | 직군에 미치는 영향 (초기값) |
| --- | --- | --- |
| 1975\~1989 | 고도성장, 수출 호조 | 기계·제조, 건설, 영업 성과 ×1.15. 게임 개발은 아직 없다 |
| 1990\~1996 | 개인용 컴퓨터 보급 | 소프트웨어·게임 개발이 열린다 |
| 1997\~1998 | 외환위기 | 모든 직군 성과 ×0.8, 구조조정·희망퇴직 카드가 자주 나온다 |
| 1999\~2001 | 닷컴 붐과 붕괴 | 개발 직군 ×1.25 뒤 거품 붕괴 카드 |
| 2008\~2009 | 세계 금융위기 | 은행·금융 ×0.8, 투자 손실 확률 상승 |
| 2010\~2019 | 모바일 시대 | 게임·소프트웨어 ×1.15 |
| 2020\~2021 | 감염병 유행 | 요리·외식 ×0.8, 의료 ×1.2, 원격 근무 카드 |
| 2022\~2026 | AI 확산 | 개발·사무 카드에 자동화 사건 |
| 2027 이후 | 없음 | 8판처럼 무작위 시대 뉴스만 (불황, 호황, 신기술 붐 등) |

- 고정 사건이 없는 해에는 8판처럼 4\~7년에 한 번 무작위 시대 뉴스가 뜨고 2년 간다. 배율은 8판 값(0.8\~1.25)을 쓴다.
- 직군마다 ‘열리는 해’를 둔다. 그 전에는 지망으로 나오지 않고, 진로 변경 후보에도 없다. 지금 10개 중에서는 게임 개발만 1990년이고 나머지는 처음부터 열려 있다.
- 이력서, 업무 수첩, 인생 요약에 나이와 함께 연도를 적는다. 예: "2003년(24세) 새벽세시 입사".
- 연도는 판 사이의 연결(이전 생의 회사)에도 쓰인다.

## 처지와 여섯 갈래 길

플레이어는 다섯 처지 중 하나에 있고, 처지에 따라 쓸 수 있는 행동이 다르다. 어느 처지에 있든 여섯 갈래 길의 층은 따로 쌓인다.

| 처지 | 어떻게 들어가나 | 쓸 수 있는 행동 |
| --- | --- | --- |
| 학생 | 시작, 대학 진학 | 공부, 알바, 대외활동, 연애·친구, 휴식 |
| 구직 | 졸업, 퇴사, 권고사직, 폐업 | 취업 준비, 알바, 인맥, 가족·일상, 휴식 |
| 직장 | 지원서 합격, 스카우트, 회사 매각 | 업무, 자기계발, 인맥, 대외 활동, 대표 업적, 투자, 가족·일상, 휴식 |
| 창업 | 사직서나 사건에서 창업 (직군별 창업 자금 3,000만\~1억) | 업무 대신 사업, 나머지는 직장과 같다 |
| 프리랜서 | 사건에서 독립 | 업무 대신 일감, 나머지는 직장과 같다 |

### 여섯 갈래 길

길마다 5층이 있고 5층이 정점이다. 정점 이름은 직군마다 다르다.

| 길 | 층이 오르는 조건 (1\~5층) | 정점 예 (소프트웨어 개발) |
| --- | --- | --- |
| 조직 | 직장 직급 2\~6단계 | 테크 기업 대표 |
| 창업 | 내 회사 단계 2\~6단계 | 테크 그룹 회장 |
| 장인 | 능력 30 / 50 / 65 + 대표 업적 1 / 78 + 2 / 90 + 3 | 전설의 개발자 |
| 명성 | 명성 15 / 35 / 55 / 75 / 88 | 스타 개발자 |
| 자산 | 순자산 5,000만 / 3억 / 10억 / 30억 / 70억 | 경제적 자유 |
| 삶 | 좋은 해(일상 75 이상, 번아웃 55 미만) 5 / 12 / 19 / 26 / 33년, 5층은 일상 80도 | 잘 산 인생 |

- 길끼리 서로 깎는다. 대외 활동은 회사 성과를 깎고, 업무만 하면 일상과 삶의 길이 무너진다.
- 정점에 오르면 그 자리에서 스스로 내려올지, 다른 길의 정점도 노릴지 고른다 (엔딩).
- 도시 풍경의 건물 여섯 동이 길 여섯 개다. 층이 오를 때마다 불이 켜지고, 5층이면 깃발이 선다.
- 다른 분야로 진로를 틀면 능력 일부를 잃고 새 직군의 첫 단계부터 다시 시작한다. 9판부터 분야 3개 중에서 고른다.

## 능력치

모든 직군과 처지가 같은 일곱 가지 수치를 쓴다. 처지를 바꿔도 쌓은 것이 이어진다. 현금을 빼면 0\~100 범위다.

| 수치 | 의미 | 주로 쓰이는 곳 |
| --- | --- | --- |
| 능력 | 직무 숙련도 | 성과 계산, 승진 조건, 장인의 길, 판정 |
| 평판 | 업계와 사내의 평가 | 성과 보정(평판÷10), 승진 조건, 스카우트 |
| 인맥 | 도움을 청할 수 있는 사람 | 구직 합격률, 높은 직급 승진, 창업 단계 |
| 명성 | 회사 밖에서 알려진 정도 | 명성의 길, 창업 이익, 프리랜서 수입 |
| 일상 | 일 밖의 삶이 단단한 정도 | 삶의 길, 번아웃 회복량 |
| 번아웃 | 쌓인 지침 (높을수록 위험) | 70 이상 행동력 -1, 100이면 쓰러짐 |
| 현금과 자산 | 돈과 집 | 창업, 투자, 자산의 길. 순자산 = 현금 + 자산 |

## 한 해의 흐름과 행동력

한 해는 계획, 사건, 결산, 다음 해의 네 박자다. 플레이어가 매년 하는 핵심 결정은 "올해 행동력을 어디에 쓸까"다.

1. **계획:** 행동력 칸을 행동에 나눠 넣는다. 같은 행동에 몰아 넣을 수 있다. 지난해 계획이 미리 채워지고, 처지가 바뀌면 기본 계획으로 바뀐다(9판).
2. **사건:** 0\~3장 (0장 12%, 1장 50%, 2장 32%, 3장 6%). 학생과 구직 중에는 최대 1장. 졸업 진로, 구직, 정점 심사, 6년마다 특성 선택은 필수다.
3. **결산:** 인사평가나 사업 결산, 수입과 저축, 번아웃 회복, 승진 판정, 버킷리스트 확인.
4. **다음 해:** 나이와 연도가 오르고, 시대 뉴스가 뜨기도 한다.

### 행동력

기본 4칸이다. 특성 ‘멀티태스커’면 +1(대신 매년 번아웃 +6), 번아웃 70 이상이면 -1, 육아 중 -1, 간병 중 -1이고 최소 2칸이다. 처음 쓰러진 다음 해는 강제 휴직이라 0칸이다.

### 행동 효과 (1칸당)

| 행동 | 처지 | 효과 |
| --- | --- | --- |
| 업무 | 직장 | 성과 +10×(0.5 + 능력÷100), 번아웃 +8 |
| 사업 | 창업 | 회사 성과 +10×(0.5 + 능력÷100), 번아웃 +8 |
| 일감 | 프리랜서 | 일감 +1, 번아웃 +8. 연 수입 = 일감 × (능력×12 + 명성×15 + 인맥×5)만 원 × 직군 단가 |
| 자기계발, 공부, 취업 준비 | 전부 | 능력 +4 (능력 50 이상 +3, 70 이상 +2, 85 이상 +0.7), 번아웃 +3 |
| 인맥 | 구직·직장·창업·프리 | 인맥 +5, 평판 +1, 현금 -100만 |
| 대외 활동 | 직장·창업·프리 | 명성 +(2 + 능력÷35 + 평판÷80) (명성 50 이상 ×0.75, 75 이상 ×0.5), 회사 성과 -3, 번아웃 +3 |
| 대표 업적 | 직장·창업·프리 | 진행 +1, 능력 +1, 번아웃 +4. 진행이 4가 되면 도전. 이름은 직군별(대표작, 대표 메뉴, 대표 실적 등) |
| 투자 | 25세부터 | 현금의 25%(최소 500만)를 건다. -60% 18%, -20% 22%, +15% 30%, +40% 20%, +120% 8%, +400% 2% |
| 가족·일상, 연애·친구 | 전부 | 일상 +8×(1 - 일상÷120) (최소 1), 번아웃 -6 |
| 휴식 | 전부 | 번아웃 -15 (45세부터 -12) |
| 알바 | 학생·구직 | 현금 +300만, 인맥 +1, 번아웃 +5 |
| 대외활동 (학생) | 학생 | 인맥 +4, 평판 +2, 번아웃 +2 |

### 해말 번아웃 회복

결산에서 번아웃이 저절로 줄어든다. 기본은 40세 미만 5, 50세 미만 3, 그 뒤 1이다. 일상 60 이상이면 +3, 40 미만이면 -7, 20 미만이면 다시 -3이라 회복이 마이너스가 될 수 있다. 번아웃 70 이상인 해는 일상이 3 줄어든다.

이 절의 수치는 8판 프로토타입에 넣은 임시값이다. 자동 플레이 시뮬레이터(tools/sim.js)로 길별 정점 달성률을 보며 조정한다.

## 승진과 평가

직장에서는 매년 인사평가 등급으로 승진 점수를 모으고, 점수와 최소 능력치를 채운 뒤 자리가 나면 승진한다. 단계는 모든 직군이 6단계로 같고 이름만 다르다.

올해 성과 = 업무 칸의 성과 합 × 상사 보정 × 시대 배율 + 평판 ÷ 10

| 등급 | 성과 | 승진 점수 | 연봉 | 평판 |
| --- | --- | --- | --- | --- |
| S | 40 이상 | +4 | +8% | +3 |
| A | 30 이상 | +3 | +5% | +2 |
| B | 18 이상 | +2 | +3% | +1 |
| C | 8 이상 | +1 | 0% | 0 |
| D | 8 미만 | 0 | 0% | -2, 2년 연속이면 권고사직 |

| 승진 | 필요 승진 점수 | 최소 능력치 | 자리가 날 확률 |
| --- | --- | --- | --- |
| 1 → 2단계 | 4 | 능력 20 | 100% |
| 2 → 3단계 | 7 | 능력 30 | 85% |
| 3 → 4단계 | 10 | 능력 40, 평판 32 | 65% |
| 4 → 5단계 | 13 | 능력 45, 평판 48, 인맥 50 | 48% |
| 5 → 6단계 (정점) | 16 | 능력 50, 평판 64, 인맥 70 + 정점 심사 통과 | 35% |

- 자리가 날 확률은 인맥 50에서 1당 0.4%p씩 오르내리고, 같은 단계의 동기가 있으면 -10%p다.
- 연봉은 단계별 기준(3,000만 / 4,500만 / 6,500만 / 9,000만 / 1억 5,000만 / 3억)에 직군 배율을 곱하고, 30%를 저축한다.
- 이직하면 연봉 +20%이고 승진 점수는 0부터 다시 모은다. 상사도 새로 뽑힌다.

## 창업 규칙

창업한 뒤에도 같은 행동력 칸을 쓰고, 업무 대신 사업을 넣는다. 회사는 6단계로 커지고, 단계가 창업의 길 층이 된다.

- **창업 자금:** 직군별 3,000만\~1억. 사직서나 사건에서 창업한다.
- **결산:** 회사 성과 = 사업 칸의 성과 합 × 시대 배율 + 평판 ÷ 10. 직장과 같은 등급표로 단계 점수를 받는다.
- **이익:** 단계별 기준액 × (성과 - 18) ÷ 20 × 변동(흑자일 때 0.55\~1.45) × (1 + 명성 ÷ 200) - 1,000만. 기준액은 2,000만 / 5,000만 / 1억 5,000만 / 5억 / 20억 / 50억이다.
- **단계 오르기:** 필요 점수는 직장 승진과 같고, 최소 조건은 인맥 15 / 30 / 45와 평판 35 / 60과 52 / 72와 66이다.
- **폐업과 매각:** 폐업은 한 번은 정리하고 다시 시작할 수 있고, 두 번째는 파산이다. 매각하면 현금을 받고 큰 회사의 임원(5단계)으로 간다.
- **나중 후보:** 직원 카드를 뽑아 만들기·팔기·지키기 부서에 배치하는 경영 시스템(초기 설계안). 아직 구현하지 않았다.

## 엔딩

한 판은 아래 네 가지 중 하나로 끝난다. 스스로 내려오는 엔딩은 정점을 하나라도 단 사람에게만 열린다.

| 엔딩 | 종류 | 조건 |
| --- | --- | --- |
| 정년 퇴임 | 정상 | 65세. 정점이 있으면 정점 이름이 제목이 된다 |
| 조기 은퇴 | 강제 중도 | 번아웃 100에 두 번째로 닿았다. 첫 번째는 1년 강제 휴직 뒤 번아웃 45로 돌아온다 |
| 파산 | 강제 중도 | 폐업한 뒤 또 폐업했거나, 순자산이 -2억 아래로 떨어졌다 |
| 스스로 내려옴 | 선택 중도 | 정점에 오른 그 순간(8판의 "박수 칠 때 떠난다"), 또는 정점을 단 뒤 사직, 사임, 희망퇴직, 회사 매각, 대표 사임을 할 때마다 "여기서 은퇴한다"를 고를 수 있다 |

- 정점이 없을 때 그만두면 8판처럼 이직, 창업, 쉬기 중에서 고르고 판은 이어진다.
- 스스로 내려온 엔딩은 그 시점의 기록으로 평가하고, 남은 해는 계산하지 않는다. 제목은 정점 직후면 "박수 칠 때 떠났다", 그 뒤의 사직이면 "스스로 내려왔다"다.
- 엔딩 화면에는 결말 문장, 마지막 명함, 이번 인생이 남긴 것(수집), 인생 그래프, 최종 이력서, 이력서에 못 쓴 이야기가 나온다. 조기 은퇴에는 원인 한 줄을 더한다(9판).

## 판 사이의 연결

끝낸 인생은 커리어 타운에 남고, 그 사람의 회사는 다음 인생에 다시 나올 수 있다.

### 커리어 타운 배치 (새로)

| 엔딩 때의 상태 | 타운에서 함께 있는 것 | 건물 크기 |
| --- | --- | --- |
| 창업하지 않았다 | 집 | 자산의 길 층: 0\~1층 빌라, 2층 아파트, 3층 주택, 4층 단독주택, 5층 저택 |
| 창업했지만 엔딩 전에 대표 자리에서 내려왔다 (매각, 사임, 폐업, 스스로 내려옴) | 집 | 위와 같다 |
| 창업해서 엔딩 때도 대표였다 | 창업한 회사 | 창업의 길 층 |

- 캐릭터는 자기 집이나 회사 앞길을 걸어 다니고, 마주치면 서로의 인생을 두고 말을 건다(8판).
- 사람이나 건물을 누르면 그 인생의 요약과 명함이 열린다.

### 이전 생의 회사 (새로)

끝낸 인생마다 시작·끝 연도, 다닌 회사, 창업한 회사와 창업 연도, 마지막 회사 단계, 끝날 때 회사 상태(운영 중, 매각, 폐업)를 기록한다. 다음 인생이 그 시대를 지나면 그 회사를 다시 만난다.

| 상황 | 나오는 방식 |
| --- | --- |
| 시대가 겹친다 (그해에 이전 생 회사가 운영 중) | 취업처 후보로 섞이고, 내가 창업하면 경쟁사로 나온다. 같은 직군이면 우선한다. 이전 생 인물이 대표나 상사로 등장한다 |
| 이전 생이 지금보다 과거다 | 가벼운 사건만: 옛 간판을 본다, 창업자 회고록이 나왔다는 뉴스, 그 회사에 다녔던 사람을 만난다 |
| 이전 생 회사가 대기업이 됐다 (창업의 길 5층) | 시대가 달라도 계속 있는 회사로 본다. 취업처, 경쟁사, 가벼운 사건(인수 합병, 위기, 몰락) 중 하나가 무작위로 나온다 |
| 이전 생이 지금보다 미래다 | 숨은 사건: 이전 생의 그 사람이 아이로 스쳐 간다. 회사는 아직 없다 |

- 확률(초기값): 시대가 겹치면 그 직군 회사 후보의 25%를 이전 생 회사로 채운다. 대기업이 된 이전 생 회사는 판마다 40% 확률로 한 번 나오고, 나올 때 취업처 40%, 경쟁사 30%, 가벼운 사건 30%(그중 1/3은 몰락)다.
- 이전 생 회사에서 받은 명함은 그 회사 브랜드로 찍히고, 도감에 따로 모인다.

### 숨은 엔딩

- 르네상스인: 정점 3개 이상
- 오뚝이: 폐업한 뒤 다시 창업해 창업의 정점
- 최연소: 42세 전에 정점
- 동기 사랑: 동기와 같이 창업해 창업의 정점
- 프로 이직러: 정점 없이 이직 7회 이상
- 만년 과장: 정점 없이 한 단계에서 20년 이상
- 한 우물: 첫 회사에서 이직·창업 없이 정년

분위기는 직장인 공감 유머로 간다. 보고서 반려, 갑작스러운 조직개편, 회식 자리 배치 같은 작은 카드가 성장 이야기 사이를 채운다.

## 출신과 특성

출신은 8종에서 하나, 특성은 장점 하나와 단점 하나를 뽑는다. 출신은 출발선을, 특성은 플레이 방식을 바꾼다. 수치는 게임용으로 정한 값이고 실제 통계가 아니다.

| 재벌가 막내 | 자금 5억, 인맥 +20 | 낙하산 선택지. 쓰면 평판이 깎인다 |

| 장점 특성 | 효과 | 단점 특성 | 효과 |
| --- | --- | --- | --- |

학력 확률은 출신에 따라 기운다. 예를 들어 20세에 수도권 대학에 입학할 확률은 전문직 집안 45%, 평범한 회사원 집안 25%, 형편이 어려운 집 12%로 시작하고, 플레이 테스트로 조정한다. 지망 직군은 학력과 연동한 가중 랜덤으로 뽑되, 10% 확률로 학력과 무관한 직군이 나와 엉뚱한 출발을 만든다.

직군은 90개(구현 10개, 2차 6개 포함)이고, 직군마다 정점 목표가 하나씩 있다. 분야는 보기 쉽게 묶은 것일 뿐 게임 안의 단위가 아니다.

## 사건 카드 구조

카드는 모든 직군이 함께 쓰는 공통 카드와 그 직군에서만 나오는 직군 카드 두 층이다. 8판에는 134장이 들어 있다.

| 층 | 8판 수량 | 내용 예 |
| --- | --- | --- |
| 공통 카드 | 약 99장 (필수 카드 포함) | 졸업 진로, 구직, 결혼, 육아, 이직 제안, 구조조정, 건강, 정점 심사 |
| 직군 카드 | 직군당 5장 안팎 (추가 7개 직군 35장) | 그 직군의 사건과 독립 갈림길 |

- 카드는 데이터 파일(data.js, jobs2.js)에 모여 있어 코드를 고치지 않고 추가한다.
- 각 카드는 등장 조건(나이, 직군, 처지, 단계, 능력치), 선택지 2\~4개, 선택별 효과를 갖는다. 선택지는 확률 판정이나 능력치 판정을 가질 수 있고, 성공률은 화면에 보인다.
- 시대 카드(외환위기, 금융위기 등)와 이전 생 회사 카드는 10판에서 연도 조건을 더해 추가한다.

샘플 카드

| 카드 | 등장 조건 | 선택지와 결과 |
| --- | --- | --- |
| **금요일 6시의 보고서** (공통) | 커리어 트랙, 1\~3단계 | ① 남아서 고친다: 성과 +5, 번아웃 +6 / ② 월요일에 하겠다고 한다: 상사가 야근형이면 평판 -4, 아니면 변화 없음 / ③ 동기에게 부탁한다: 인맥 -3, 동기 호감도 -1 |
| **동기의 사업 제안** (공통) | 28\~40세, 동기 호감도 높음, 자금 3,000만 원 이상 | ① 같이 나간다: 경영 트랙으로 전환, 동기가 첫 직원 카드 / ② 투자만 한다: 자금 -2,000만 원, 5년 뒤 결과 카드 / ③ 거절한다: 동기가 혼자 창업하고 이후 근황에 계속 등장 |
| **출시 3일 전, 치명적 버그** (게임 개발) | 게임 개발 2\~4단계 | ① 출시를 미룬다: 평판 +3, 성과 -5 / ② 밤새워 고친다: 능력 60 이상이면 성공(성과 +10), 아니면 실패(평판 -8, 흑역사 기록), 번아웃 +12 / ③ 일단 내고 패치한다: 50% 확률로 넘어가거나 평판 -10 |
| **건물주의 통보** (요리·외식) | 경영 트랙, 1호점 운영 중 | ① 월세 인상을 받아들인다: 매년 자금 -600만 원 / ② 옆 동네로 옮긴다: 자금 -3,000만 원, 단골 절반 유지 / ③ 대출로 건물을 산다: 자금 -2억(빚), 이후 월세 없음 |

## 개발 단계

지금은 11판이다. 판마다 GitHub 브랜치(v1\~v11)가 하나씩 있고, 배포 주소 뒤에 /v3/처럼 판 번호를 붙이면 지난 판을 해 볼 수 있다.

| 판 | 주요 내용 |
| --- | --- |
| 1판 | 첫 프로토타입. 직군 3개, 무작위 출발, 65세 정년 |
| 2판 | 여섯 갈래 길, 인생 사건, 난이도 상향 |
| 3판 | 파일 분리, 도시 스카이라인, 포스트잇 계획, 인사발령. 첫 공개 |
| 4판 | 효과음과 연출, 버킷리스트, 수집첩 |
| 5판 | 한 화면 게임판 |
| 6판 | 명함 132종, 처음 하는 사람 안내, 검토 수정 |
| 7판 | 직군 10개, 명함 433종 |
| 8판 | 커리어 타운, 인생 요약, 직군별 대표 업적 이름, GitHub Pages 배포 |
| 9판 | 처음 하는 사람 기준 개선(다가오는 결정, 계획 미리보기, 클릭 줄이기), 스스로 내려옴 엔딩 |
| 10판 | 시작 연도와 고정 시대, 시대 카드, 지난 인생의 회사, 커리어 타운 집·회사 배치 |
| 11판 | 명함 다양화(직급 마감, 시대 양식, 직군 신분증, 드문 변형), 사건 카드 그림, 화면 디자인 보완 |
